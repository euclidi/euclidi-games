# Night Watch

Standalone retro first-person shooter, version 0.1.0. Explore a compact compound, collect weapons and supplies, fight hooded sentries, recover a keycard and extract.

[Play](https://euclidi.github.io/euclidi-games/night-watch/) · [Catalog](https://euclidi.github.io/euclidi-games/) · [Specification](SPEC.md) · [Roadmap](ROADMAP.md) · [Status](STATUS.md)

WASD move, mouse or arrows aim, Space or click fire, R reload, 1–3 select weapon, M map, Escape pause. Touch and standard gamepad supported. Serve this folder via HTTP; no dependencies or external assets. Run `npm test` for simulation tests.

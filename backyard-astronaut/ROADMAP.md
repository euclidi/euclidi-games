# Backyard Astronaut — Roadmap

Updated 2026-11-26. Active — unified V2 preview; Alpha 0.3 retained.

This is an ordered development backlog, not a declaration that milestones are complete. Internal sequencing does not introduce approval stops; explicit project gates and archive restrictions remain binding.

## Priorities

- [ ] Improve high-detail independent part/character art, animation and collision bounds; inspect all camera angles.
- [ ] Complete physical assembly/joints, torque, mass properties, staging and terrain/flight frame continuity.
- [ ] Validate orbital references, transfers, flybys, landings, return and persistent identity across transitions.
- [ ] Expand connected world, progression and solar system; complete input/audio/save migrations and full playthrough.

## Release discipline

- [ ] Record changes and known regressions in [STATUS.md](STATUS.md).
- [ ] Run relevant automated logic and browser checks, visual inspection, input and persistence tests; attach evidence to the release commit.
- [ ] Verify the actual GitHub Pages release and catalog links before labeling a build verified.

# Sugarworks — Maribel's Cottage

A first-person confectionery-world plumbing service visit, with an explorable five-room cottage, autonomous owner Maribel, repair tools, dialogue and payment.

- Current source: [v4.2](index.html) (development preview, browser playtest pending).
- Preserved baseline: [v4.1](legacy/v4.1.html), recovered from the previous standalone project.
- [Scope](SPEC.md) · [Roadmap](ROADMAP.md) · [Status](STATUS.md)

Controls: WASD/arrows, drag to look, E to interact, 1–4 tools, F swaps view. Touch pad and interaction button on mobile; browser gamepad A/Y and shoulder buttons. Scene mode permits direct object selection. Begin by talking to Maribel; isolate supply, wait for residual pressure to fall, loosen trap, fit gasket, restore pressure, run leak test, plunge until blockage breaks and collect payment. Optional tea. New visit clears saved state after confirmation.

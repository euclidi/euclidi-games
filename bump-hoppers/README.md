# Bump Hoppers

A 1982-style isometric arcade game. Bounce on every cube to change its color, avoid roaming creatures, and use rescue discs to return to the summit. Arrow keys, Q/E/Z/C, WASD, adjacent cube taps, diagonal touch pad and standard gamepads are supported. Enter/A starts and advances rounds; Escape pauses.

Engine: Phaser 3.90.0 (MIT), pinned CDN. Native 240 × 256 portrait raster, original hand-mapped pixel sprites, bitmap font, flat-color cube faces, no gradient art. Web Audio effects and local high score.

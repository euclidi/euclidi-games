# Bump Hoppers

A clay-style isometric arcade game. Bounce on every cube to change its color, avoid roaming creatures, and use rescue discs to return to the summit. Arrow keys, Q/E/Z/C, WASD, adjacent cube taps, diagonal touch pad and standard gamepads are supported. Enter/A starts and advances rounds; Escape pauses.

Engine: Phaser 3.90.0 (MIT), pinned CDN. Original runtime-rasterized clay-style sprites and Web Audio synthesized effects. No external art assets. High score stored locally.

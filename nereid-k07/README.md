# NEREID K-07
First-person submarine simulation. Original seven-compartment build preserved; v3.3 is a development checkpoint, not a finished release.

[Development build](https://euclidi.github.io/euclidi-games/nereid-k07/)

Controls: WASD / left stick, drag / right stick to look, E / A to interact, Esc / B to leave a station. Touch movement pad and station buttons. At helm, man the station first, use heading buttons or A/D / left stick, throttle and ballast. In the manipulator station, drag to aim and grip/release near sample or bin. Sound is opt-in. Controller mappings can be configured.

Three.js r180 (MIT) via pinned CDN with fallback. Browser WebGL and network access required. See SPEC, ROADMAP and STATUS for scope, priorities and verification.

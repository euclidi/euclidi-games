# TENPIN

A swipe-first ten-pin bowling game developed from the original STACK SIM bowling prototype. Play at https://euclidi.github.io/euclidi-games/tenpin/ .

Swipe up from the desired release position; faster gestures generate higher release velocity, diagonal gestures alter aim and curved gestures add hook. Keyboard arrows and Space are available; standard-mapped gamepads can aim with the left stick and charge/release with A or right trigger. Three cameras, sound toggle, ten-frame scoring and local best score are included.

The current build is a development preview, not a verified release. Three.js r180 and cannon-es 0.20.0 are MIT-licensed dependencies loaded from a pinned CDN. Browser access to these dependencies and WebGL is required.

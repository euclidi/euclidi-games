# Through the Boards — development roadmap

This is a dependency-aware work queue, not a sequence of user-facing approval gates.

1. **Source continuity:** preserve v0.14.1 binary/browser baseline, v0.15 portable-save build and executable regression contract in GitHub. Search for original C source; if unrecoverable, implement a compatible C reconstruction in a separate branch, with reproducible native and WASM compilation and differential tests against the preserved binary. Do not promote until behavior/save parity is verified.
2. **Physical interaction:** articulated posture and visible hand contact; dynamic chair orientation and collision; localized mattress and pillow load/recovery; 3D cloth/cable constraints and nonpenetration; persistent settled state.
3. **Environmental fidelity:** authored sprite-stack assets, precise depth, physically plausible aperture light transport and material absorption/reflection, CRT emission; spatial acoustics and outdoor ambience. No plot or scope expansion.
4. **Everyday activity:** deepen ROOM/OS and quiet interactions, maintain customizable avatar and journal.
5. **Release quality:** cross-device snapshot migration, real mobile/desktop testing, frame-time measurements, actual audible quality, production URL verification, rollback and catalog maintenance. Preserve previous builds; keep all modified source and tests committed together.

For every pass: audit latest GitHub files and scope, select appropriate technology and licensed assets, implement substantial cohesive improvements, run regression tests, inspect rendered results, report failures and measured evidence, commit recoverable artifacts and update status. Maintain a single authoritative baseline.

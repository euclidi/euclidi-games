# Through the Boards

A quiet single-room isometric sprite-stacked bedroom simulation. The boarded door and windows remain unexplained.

[Play development build 0.16](https://euclidi.github.io/euclidi-games/through-the-boards/)

Keyboard, touch and tap navigation; customizable character; movable chair, mattress, blanket and cables; passing time, weather, light and room acoustics; local offline ROOM/OS. Use **Transfer Save** to copy a room snapshot and restore it on another browser or device. Save text is local; do not publish private journals.

The browser preview contains the preserved C-derived WebAssembly simulation and JavaScript renderer/audio. Original editable C99 source is currently missing. A compiled binary is not source. Do not claim that this repository supports native compilation until source is recovered and verified.

See [SPEC](SPEC.md), [ROADMAP](ROADMAP.md), [STATUS](STATUS.md). Historical build: [0.14.1](legacy/preview-v0.14.1.html). Run `node regression-v15.cjs index.html` to check the existing compiled simulation.

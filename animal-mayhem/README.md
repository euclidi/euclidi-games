# Animal Mayhem
Development build 0.1.0 (unpublished). Mobile landscape indoor cat sandbox. Move with left analog; tap A to jump, hold A to pounce; tap B to interact or swat, hold B to carry. Keyboard: WASD/arrows, Space, E. Journal revisits unlocked homes. No aging past adulthood or mandatory survival chores.

Three.js 0.170.0, Rapier 0.17.3, glTF, Web Audio, IndexedDB. Copies of the runtime libraries and household models are stored under `vendor/` and `assets/` for future development; the existing game still loads its dependencies remotely. See [asset provenance and candidate roster](assets/README.md) and [SHA-256 inventory](assets/SHA256SUMS.txt). The cat is by madtrollstudio, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), via [Poly Pizza](https://poly.pizza/m/YvVobPlTlQ); it is resized in-game. The furniture pack attribution is an upstream identification that still needs exact model-to-pack confirmation. Candidate species models are not yet integrated or playable.

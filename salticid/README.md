# Salticid — Canopy
Browser-based jumping spider simulation. Open the [development build](https://euclidi.github.io/euclidi-games/salticid/).
## Controls
A/D or arrows: move; Space: hold and release to jump; E: tether/release; R: reel; F: stalk; Q: weave. On-screen buttons support touch. Gamepad: left stick or D-pad, south jump, west silk, north stalk, east weave, right bumper reel. Tap a fly to aim; drag the scene to orbit. Help pauses simulation. 
## Runtime
Three.js r170 (MIT), WebGL 2, 120 Hz fixed-step gameplay. External CDN dependency; startup errors are displayed. The earlier V3 source was migrated rather than replaced with a reduced demo.

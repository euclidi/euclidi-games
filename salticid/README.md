# Salticid — Canopy
Browser-based jumping spider simulation. [Open development build](https://euclidi.github.io/euclidi-games/salticid/?v=0.2.0).
## Controls
A/D or arrows: move; Space: hold and release to jump; E: tether/release; R: reel; F: stalk; Q: weave. Touch buttons. Gamepad: left stick/D-pad, south jump, west silk, north stalk, east weave, right bumper reel. Tap a fly to aim; drag to orbit; help pauses.
## Runtime
Three.js r170 (MIT), WebGL 2, 120 Hz fixed-step gameplay. 0.2 preserves the existing project and adds an optional GLB fly render pipeline and compliant tether. External CDN dependencies remain.
## Assets
[House Fly](https://vinish.dev/free-3d-models/insects) by vinish.dev, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), adapted scale/orientation and animation playback; browser-side load attempted with procedural fallback. Asset download and runtime appearance unverified. Existing spider and habitat are procedural pending acquisition and rig audit. See SPEC.md, ROADMAP.md and STATUS.md.

# Reusable game resources

These are unused building blocks, not additions to live games. Choose a pack compatible with the project's established style; do not mix pixel scales within a layer.

- `kenney-1bit/`: 1-Bit Pack 1.2 tile sheets, including transparent and packed variants. [Upstream](https://kenney.nl/assets/1-bit-pack); CC0, original license included.
- `kenney-input-prompts-pixel/`: Input Prompts Pixel 16 tile sheets and tile index for keyboard/controller prompts. [Upstream](https://kenney.nl/assets/input-prompts-pixel-16); CC0, original license included.
- `kenney-crosshairs/`: 20 white PNG crosshairs from Crosshair Pack. [Upstream](https://kenney.nl/assets/crosshair-pack); CC0, original license included.
- `tech/javascript-state-machine/`: browser-ready finite-state-machine library, history and visualization plugins, plus upstream README and MIT license. Upstream commit `2ae84bbbaad13103be43b3e0a24c077002e2301a`: https://github.com/jakesgordon/javascript-state-machine . Import only when a project needs it; assess maintenance and performance first.

Packs are curated subsets from the shared `D:/Assets` source archives, copied unchanged. Check individual licenses before redistribution. None are integrated or visually validated in a game.

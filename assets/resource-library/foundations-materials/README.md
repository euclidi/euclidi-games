# Prototype grids and material maps

- [Kenney prototype grids](kenney-prototype-grids.zip) contains 78 original PNGs and the original license from [Prototype Textures](https://kenney.nl/assets/prototype-textures). Use the grid images for level scale and collision blockouts.
- [Poly Haven source map catalog](sources.json) lists concrete flooring, plank flooring and cobblestone. Each set contains 1K diffuse, OpenGL normal and roughness JPEGs. Read diffuse as sRGB and normal and roughness maps as non-color data. Check the normal convention on import.

The maps are CC0. The catalog records each provider and file digest. [Poly Haven license](https://polyhaven.com/license)

# Audio foundations

Seven CC0 Kenney source packs are stored as separate ZIPs under `kenney/`. Each archive contains its license and original files. Preserve the source folder structure when extracting and select sounds by context rather than renaming over another pack's generic filenames.

| Archive | Coverage | Source |
|---|---|---|
| `impact-sounds.zip` | Impacts, hits, movement, and object sounds | [Impact Sounds](https://kenney.nl/assets/impact-sounds) |
| `rpg-audio.zip` | RPG actions, footsteps, weapons, and ambience | [RPG Audio](https://kenney.nl/assets/rpg-audio) |
| `sci-fi-sounds.zip` | Electronic and sci-fi effects | [Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds) |
| `interface-sounds.zip` | UI and interaction cues | [Interface Sounds](https://kenney.nl/assets/interface-sounds) |
| `digital-audio.zip` | Digital bleeps, tones, and effects | [Digital Audio](https://kenney.nl/assets/digital-audio) |
| `ui-audio.zip` | Interface and feedback sounds | [UI Audio](https://kenney.nl/assets/ui-audio) |
| `music-jingles.zip` | Short musical stings and jingles | [Music Jingles](https://kenney.nl/assets/music-jingles) |

These are source recordings/effects, not a balanced production mix. Check loudness, loop points, sample rate, and platform format in the target project. The synthetic signal tests in `euclidi-labs` are separate digital-pipeline fixtures, not replacement SFX or acoustic calibration data.

Deepvein Mine | v1.2.1

Collection studio refresh

This Studio folder includes the editable Blender presentation, the render used
on itch.io and the coordinated cover. Open Studio.blend in Blender 4.5 or newer.
Use the scene selector at the top of Blender to switch from the studio to the
original scene. The studio places the existing kit pieces in a staged diorama.
The display base and background are presentation geometry.

The game-ready exports, existing source files, Godot demo and all other files
from version 1.2.0 are included with their original contents. For the
playable demonstration and integration steps, refer to the original README.

# Vinish.dev bricks, rubble, and debris models

- Official source: https://vinish.dev/free-3d-models/bricks-rubble-and-debris
- License: CC BY 4.0; source license: https://creativecommons.org/licenses/by/4.0/
- Keep the per-model credit in each GLB and use the matching `attribution_text` in `source-record.json` or `sources.json`.
- Twelve GLBs are included. Publisher-documented sizes range from 1,424 to 9,364 triangles; every model is metre-scale and rests on the ground plane.
- The source says the component shapes inside the rubble meshes can be separated in a 3D tool. These are static break-state models; no masses, inertias, collision presets, impulses, or fracture solver are supplied.
- `source-record.json` lists all model hashes, dimensions, triangle counts, official source page, and attribution.

Development branch — unpublished, not a playable release.

Approved fictional medieval projectile/life sandbox. See SPEC.md, ROADMAP.md, STATUS.md and ASSETS.md. The committed ES module is a renderer-independent mathematical simulation/progression foundation, not a substitute for the approved Babylon.js + Havok game.

Run `node kinetic/tests/core.test.mjs` from the repository root. No dependencies required for core tests. Runtime integration, visual benchmark, package lock, browser tests, catalog registration and deployment remain required.

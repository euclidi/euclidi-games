## Development rules

- Commit code and fixed regression fixtures before deploying; keep all DOJO changes within this directory.
- Preserve experimental parameters, numerical measurements, outcomes and reproducibility metadata. Export browser-local IndexedDB archives as JSON before changing origin/device; Git does not automatically synchronize browser storage.
- Evaluate physics and human visual quality separately. Retain failed experiments. Require multidirectional balance, anatomical integrity, physical contact and measured mobile performance before approving Stage 1.
- Preserve the stickman aesthetic; prefer established licensed engines and real motion assets. Do not claim visual or device tests that were not performed.

# Development 0.1 status

Initial Git-hosted development port. Core model tested in a JavaScript isolate over 600 simulated seconds: both miners delivered materials, excavated rock, built supports and produced credits. Browser rendering, motion appearance and live GitHub Pages deployment not verified at commit time. The artwork is interim hand-authored pixel masks plus procedural terrain and some drawn props; the requested high-fidelity sprite assets and contact animations remain unfinished. Collapse uses a span heuristic, not a geological stress solver. No durable save or real rigid-body transport. The two transport sprites remain similar. No new cover artwork is published; catalog uses a title-only entry. Browser smoke script provided for CI execution, not claimed as passing.

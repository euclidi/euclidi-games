# The Meeting Seam

[Play the development build](https://euclidi.github.io/euclidi-games/meeting-seam/).

Two autonomous miners advance from opposing ends of an irregular rock seam. Arthur uses a pick and timber supports; Elias drills and stages steel supports and railway construction. Observe both, speed up time, invest shared credits or intervene in the terrain and infrastructure. This is an early Git-hosted port of the chat prototype, not the approved final artwork. No installation required. See [SPEC](SPEC.md), [ROADMAP](ROADMAP.md), and [STATUS](STATUS.md).

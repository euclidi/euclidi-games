# SPINFORGE VII — Competition Laboratory
Development candidate 0.7.0. Browser spinning-top duel and experimental physics lab continued from VI (archived). Four original tops, four discs/drivers, three stadiums.

Run from repository root: `python3 -m http.server 8000`; visit `http://localhost:8000/spinforge/`. Three.js r169 is vendored; no CDN. WebGL is primary; old 2D view is diagnostic only. Catalog admission withheld pending genuine WebGL testing and cover.

Swipe to launch; tap to spend spin on steering. Choose parts and stadium before a round; camera and slow-motion controls retained. [Spec](SPEC.md) · [Roadmap](ROADMAP.md) · [Status](STATUS.md).

Tests: `node spinforge/tests/core.mjs`. Source: original VI conversation artifact; [Three.js r169](https://github.com/mrdoob/three.js/tree/r169) MIT license in vendor. No third-party artwork claimed.

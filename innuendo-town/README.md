# Innuendo Town
A standalone top-down urban comedy sandbox for adult fictional characters. Development build 0.4 (unreleased).
 
Run from an HTTP server, not file://. The game uses Phaser 3.90 with native Arcade Physics, a vendored original 432×288 Kenney RPG Urban atlas, and separate simulation content. Controls: WASD/arrows, Shift, E; touch D-pad, ACT, and destination selection.

## Credits

Original bitmap is stored as a data URI in assets/urban-atlas.js.
- Phaser 3.90.0, MIT, [upstream](https://github.com/phaserjs/phaser). Local vendor/phaser.min.js preferred; pinned public CDN fallback until local distribution is available.
 
No previous chat renderer is required. This branch is not the published game catalog.

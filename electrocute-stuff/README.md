# Electrocute Stuff — VoltageLab

Virtual electrical experimentation sandbox. V3 retains all seven V2 specimens and tools, with separate thermal zones, better circuit checks and debris collisions.

[Play development build](https://euclidi.github.io/euclidi-games/electrocute-stuff/)

Drag probes, hold Shock or Space, and use the inspector to observe the simulated thermal zones. Water, grounding, capacitor pulses, slow motion, audio and imperial/metric controls are available. This is a fictional game model, not real-world electrical guidance.

See [SPEC](SPEC.md), [ROADMAP](ROADMAP.md) and [STATUS](STATUS.md).

[V5 asset-first preview](https://euclidi.github.io/euclidi-games/electrocute-stuff/v5.html) — new contact geometry, Matter debris fixes and CC0 visual/audio assets. Logic regression passed; full browser playtest remains outstanding. See [ASSETS.md](ASSETS.md).


[V6 development preview](https://euclidi.github.io/euclidi-games/electrocute-stuff/v6.html): persistent specimen rack, local water brush and optional authored soda-can model. Select **WATER BRUSH ON**, drag over a specimen, then turn it off to control probes. Tab switching preserves the experiment; REPLACE OBJECT resets the selected slot. CAN MODEL PILOT is optional. See [STATUS](STATUS.md) for verification limitations.


[V7 unified live 3D preview](https://euclidi.github.io/euclidi-games/electrocute-stuff/v7.html): the entire workbench renders with live meshes when WebGL initialization succeeds. Use RESET PROBES to fit the active specimen. LOADING / LIVE 3D / 2D FALLBACK status indicates actual renderer selection. Prior rack data imported; previous builds retained. Browser rendering remains unverified.

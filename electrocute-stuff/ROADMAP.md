# Development roadmap

Complete-first workflow: preserve cumulative baseline, audit, evaluate compatible reusable technologies and assets, implement agreed scope to maximum feasible extent, regression test, then publish and refine.

- Replace approximate contacts with specimen-specific surface/component geometry and electrical networks.
- Expand coupled thermal zones into material-specific failure, deformation and fracture; implement spatial moisture and multi-object workbench.
- Evaluate mature rigid-body libraries and asset pipelines; replace circle proxy contacts with shape-level collisions and constraints; improve electrical effects and audio.
- Complete persistent experiment restoration, discovery balancing and accessibility; verify actual touch, input cancellation, performance and browser compatibility.
- Publish catalog revisions only after meaningful playtesting; keep previous working source in version history.

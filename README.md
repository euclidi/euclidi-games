# Euclidi Games

A collection of browser-based games, simulations, and interactive experiments. Explore current development builds directly in your browser, with no installation required.

**[Browse and play the game catalog](https://euclidi.github.io/euclidi-games/)**

Projects are actively developed and may contain unfinished features or experimental mechanics.

Related project: [Euclidi Labs catalog](https://euclidi.github.io/euclidi-labs/) · [Euclidi Labs repository](https://github.com/euclidi/euclidi-labs)

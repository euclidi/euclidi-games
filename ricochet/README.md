# RICOCHET
Original retro peg-clearing arcade game. [Play](https://euclidi.github.io/euclidi-games/ricochet/) · [Catalog](https://euclidi.github.io/euclidi-games/)

Development 0.1; source implementation, not a verified complete release. Aim with mouse or drag, Fire or Space to launch. Clear orange pegs; use the moving bucket to recover ammunition. Eight modes, five themes, 50 algorithmically composed campaign boards, local progression and JSON editor. Gamepad support uses the browser Gamepad API.

PixiJS 8.6.6 and Rapier 2D compat 0.17.2 are pinned CDN ES modules; WebGL and network access required. Original runtime bitmap textures and original synthesized audio, no commercial art or music copied. Run a static HTTP server at repository root to develop. Run `node ricochet/test.mjs` for content checks. See SPEC, ROADMAP and STATUS for approved scope and gaps.

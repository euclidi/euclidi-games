# RICOCHET — approved specification 1.0
Retro pixel art; classic arcade physics; efficiency and scoring objectives; traditional power-ups. Eight modes: campaign, endless, efficiency, high score, incremental, daily challenge, sandbox, editor. Five worlds with 10 handcrafted levels each. Animated bitmap art, traditional pegs and moving bucket, eight powers (guide, multiball, fireball, flippers, wide bucket, precision, extra ball, score rush), trick shots and scoring. 120 Hz continuous collision detection, consistent aim prediction, stuck recovery and slow motion. Original music/ambient/SFX with separate controls. Keyboard, pointer, touch, gamepad, remapping, accessibility palettes and scaling. Local persistence and versioned level import/export. Approved PixiJS 8, Rapier 2D WASM, TypeScript, Vite, IndexedDB, Web Audio, Vitest/Playwright and GitHub Pages. Complete-first implementation, playtest and disclose gaps. Current implementation uses browser ES modules rather than TS/Vite; see STATUS.

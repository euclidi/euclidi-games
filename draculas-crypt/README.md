# Dracula — The Vigil
Atmospheric Gothic crypt simulation with a sole autonomous rat priest. Version 0.13.0 asset-first migration candidate from cumulative V11. [Candidate route](https://euclidi.github.io/euclidi-games/draculas-crypt/) (Pages unverified; not catalog-listed). Controls: drag orbit, scroll/pinch zoom, five views, pause, follow, flames, mist, sound, browser gamepad left stick/right Y/shoulders. Run from repository root with python3 -m http.server 8765; visit /draculas-crypt/. Three.js 0.160.1 pinned CDN; ?renderer=software selects labeled compatibility view.

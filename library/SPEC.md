# Automatic Software Library — v1.1
Approved 2026-11-27. Panoramic mechanical catalog, responsive to desktop and mobile. Real-time Three.js r170 (MIT, self-hosted), physical-material cover textures, rotary storage by category, ejector, roller belt, elevator, retrieval door, inspection with pointer/touch/keyboard, optional Web Audio, motion enabled by default, Classic View retained. The classic HTML is the authoritative inventory; game launch, alternative builds and documentation are parsed directly.
## Implementation choices
Procedural bevelled meshes and spring-like animation rather than Blender/glTF or Rapier; deterministic kinematic retrieval, not a physically simulated contact solver. Existing title and color identities used on newly generated printed labels; only the existing Dummy Lab cover is imported. Three.js uses WebGL2; classic page remains accessible if initialization fails. Audio is opt-in because browsers restrict autoplay. Storage uses three boxes per visible sector with paging; other category sectors visible in the background. No invented game screenshots.

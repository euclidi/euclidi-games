# Euclidi Automatic Software Library
Open [Mechanical View](https://euclidi.github.io/euclidi-games/library/) or [Classic View](https://euclidi.github.io/euclidi-games/?view=classic). Select a category or search, select a box, inspect by hover/drag, retrieve it through the rotary system, then play. Instant Play bypasses the mechanism. Sound is opt-in; Motion On is default. Keyboard accessible controls and arrow-key box rotation.
See SPEC.md, ROADMAP.md and STATUS.md. Vendor Three.js r170 is MIT licensed.

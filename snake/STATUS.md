# Status — 0.1.2 hardware and display revision

LCD changed to direct indexed texel reads, native device-pixel GPU output, reduced default persistence (old .12 default migrates to .02), no contrast pedestal or heavy cell-gap darkening, opaque menu, and matching software contrast. Shell redesigned with molded seam, recessed bezel, power lens, D-pad, keycaps, speaker slots and motion-reactive chassis lighting. Mobile layout detected by primary coarse pointer or touch plus compact viewport, supports portrait and short landscape, respects safe areas and dynamic viewport height, and hides desktop field notes. Tilt uses DeviceOrientation events, neutral calibration, screen-axis correction, smoothing, bounded movement and explicit permission on platforms requiring it; reduced-motion preference disables tilt. Only chassis plate and highlights tilt; LCD and touch targets remain stable. No tilt gameplay steering. Browser checks expanded for desktop, portrait and landscape, fallback, fit and synthetic orientation when supported. Pure orientation and detection assertions passed in development; browser rendering, physical sensor and deployment not verified. Earlier approved engine and simulation limitations remain.

# Status — 0.1.1 startup repair

User reported every menu button inert in 0.1. Source inspection identified a reserved GLSL identifier, `active`, in the fragment shader, which could abort startup before event registration. Renamed to `pixelMask`; shader/link/context initialization now falls back to presenting the existing indexed bitmap buffer through a software LCD renderer. Settings and menu remain available even if neither graphics context can initialize. Audio initialization failures no longer abort start. Versioned resource URLs and offline cache updated.

Local full-browser verification unavailable (Chromium graphics initialization failed in the execution environment); the updated CI tests exercise both GPU and deliberately disabled WebGL paths. Do not claim live deployment or successful browser playtest without results.
